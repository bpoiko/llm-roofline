Arrival checklist:
1. `git clone` / copy the repo, `uv sync --extra mlx`, `brew install llama.cpp`, install Ollama.
2. `uv run suite.py check`: confirm the slug prints as `m5pro-64gb` (otherwise rename the key in `config/machines.json` and this directory).
3. Check `gpu_mem_budget_gb` against `sysctl iogpu.wired_limit_mb` (0 = default ≈ 48 GB).
4. `uv run suite.py fetch && uv run suite.py all`. The `suite.m5pro-64gb.toml` override adds 64k depth.
5. M5 GPUs have neural accelerators (llama.cpp logs "tensor API disabled for pre-M5" on the M4), so expect prefill to change much more than decode. Decode should follow bandwidth: ~307 vs 273 GB/s gives ~1.12× on the same model files.
